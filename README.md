
# SocialBook

A modern social media platform to connect with friends, share moments, and discover content.

## Download

- **Android**: [Download APK](https://github.com/Akhil24thakur/thesocialbook/releases/latest/download/SocialBook.apk)

## Website

- **Live**: [https://akhil24thakur.github.io/thesocialbook](https://akhil24thakur.github.io/thesocialbook)

## Features

- Posts & Feed
- Stories
- Reels
- Messages
- Live Video
- Search & Discover
- Notifications

## Tech Stack

- **Mobile**: React Native (Expo)
- **Backend**: Node.js + Prisma + Supabase
- **Website**: Next.js + Tailwind CSS (GitHub Pages)
- **Notifications**: Firebase Cloud Messaging
