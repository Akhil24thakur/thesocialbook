
# SocialBook

A modern social media platform to connect with friends, share moments, and discover content.

## Download

- **Android**: [Download APK](https://github.com/Akhil24thakur/thesocialbook/releases/latest/download/app-release.apk)

## Website

- **Live**: [https://web-nu-three-39.vercel.app](https://web-nu-three-39.vercel.app)

## Features

- Posts & Feed
- Stories
- Reels
- Messages
- Live Video
- Search & Discover
- Notifications

## Tech Stack

- **Mobile**: React Native (Expo)
- **Backend**: Node.js + Prisma + Supabase
- **Website**: Next.js + Tailwind CSS (Vercel)
- **Notifications**: Firebase Cloud Messaging
